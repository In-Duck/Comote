# Comote 계정 연결 사용법

## 일반 사용

Manager와 Client에서 같은 Comote 아이디 또는 이메일과 비밀번호로 로그인합니다. VPN 주소, Manager IP, 포트, 별도 접속 암호는 입력하지 않습니다.

Client 로그인 직후 PC가 계정에 등록되고 시스템 트레이에 Comote 아이콘이 남습니다. Manager는 시작 후 최대 약 2~3초 안에 새 PC를 다시 조회합니다. 네트워크 지연이 있으면 10초 정도 기다린 뒤 목록을 확인하세요.

## Client 트레이 메뉴

- 연결됨: 현재 등록 이름 확인
- 입력: 가상 HID 또는 SendInput 확인
- 고급 설정: PC 이름, 모니터, 입력 모드 변경
- 로그아웃: 저장된 계정 토큰과 로그인 정보 제거
- 종료: Client 완전 종료

## 연결되지 않을 때

1. 두 프로그램이 정확히 같은 아이디/이메일로 로그인했는지 확인합니다.
2. Client 트레이 아이콘이 떠 있는지 확인합니다.
3. PC 시간을 Windows 자동 설정으로 맞춥니다.
4. 회사·학교 방화벽에서 HTTPS, WebSocket, WebRTC UDP가 차단됐는지 확인합니다.
5. 엄격한 NAT 환경은 팀 TURN 설정이 필요합니다.

방화벽 포트를 여는 도구는 예전 TCP Hub 고급 모드 전용이며 기본 패키지에는 포함하지 않습니다. 일반 계정 연결에서는 방화벽 수신 규칙을 추가하지 않습니다.

## FakerInput

가상 HID를 선택했고 FakerInput을 새로 설치했다면 Client를 완전히 종료한 뒤 다시 실행합니다. 장치가 계속 인식되지 않으면 Windows를 한 번 재부팅합니다. 설치가 없어도 Comote는 SendInput으로 자동 전환합니다.
