# Comote 원격 입력 구조

## 입력 모드

| 모드 | 구현 | 용도 | 제한 |
|---|---|---|---|
| 1 | Windows SendInput | 일반 프로그램과 기본 원격 제어 | 일부 게임, 보안 화면, 높은 권한 창에서 무시될 수 있음 |
| 2 | 공식 FakerInput v0.1.1 가상 HID | SendInput을 받지 않는 프로그램에서 키보드·마우스 입력 시도 | 게임/안티치트별 허용 여부가 다르며 작동·제재 없음이 보장되지 않음 |

모드 2는 Ryochan7의 공식 FakerInput 배포 파일을 수정하지 않고 사용합니다. Comote 패키지 빌드는 MSI의 Authenticode 서명과 고정 SHA-256을 검사하고, Client는 설치 직전 SHA-256을 다시 검사합니다.

고정 SHA-256:
`4C0AEFB7340051A91D606776243298B5CD1143EF5508BBAE6800C474F9ED0840`

FakerInput은 MIT 라이선스이며 `ThirdParty/FakerInput-LICENSE.txt`를 패키지에 포함합니다.

## 장애 처리

- 연결 종료, 입력 채널 종료, 창 포커스 해제 시 눌린 키와 마우스 버튼을 해제합니다.
- FakerInput 쓰기가 실패하면 Client가 종료되지 않고 해당 실행 세션만 SendInput으로 자동 전환합니다.
- 드라이버가 끊어진 순간의 HID 해제는 운영체제와 드라이버 상태에 따라 완전히 보장할 수 없습니다. 이상 입력이 남으면 Client를 종료하고 재부팅합니다.
- 6키 동시 입력 제한은 FakerInput 키보드 보고서 형식의 제약입니다.
- 한글 등 `VkKeyScan`으로 변환할 수 없는 텍스트는 가상 HID 문자 입력 대신 클립보드 붙여넣기를 사용합니다.

## 게임 사용 주의

FakerInput이 오픈 소스이고 Microsoft 서명으로 설치된다는 사실은 특정 게임의 이용약관이나 안티치트 허용을 의미하지 않습니다. 숨김, 장치 위장, 안티치트 우회 기능은 Comote에 넣지 않습니다. 중요한 계정에서는 게임 운영사의 원격 입력·가상 장치 정책을 먼저 확인하고, 허용이 불명확하면 모드 1 또는 일반 원격 데스크톱만 사용하세요.
