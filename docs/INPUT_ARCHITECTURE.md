# Comote 원격 입력 구조

## 목표

물리 마우스와 키보드가 연결되지 않은 Windows PC도 원격 조작한다. 현재 배포판은
Windows `SendInput`을 사용하고, 이후 서명된 가상 HID 드라이버를 선택형 입력
백엔드로 추가한다.

## 현재 입력 경로

1. 매니저가 원격 영상의 실제 표시 영역을 기준으로 좌표를 0~1 범위로 정규화한다.
2. 마우스 이동·버튼·휠과 키보드 이벤트를 WebRTC DataChannel로 전송한다.
3. 클라이언트가 선택된 모니터의 가상 데스크톱 좌표로 복원한다.
4. 클라이언트의 `SendInputBackend`가 Windows 입력 큐에 이벤트를 주입한다.
5. 클라이언트가 이벤트 종류를 매니저에 응답한다.
6. 매니저 원격창에 `입력: 연결 중`, `준비`, `수신 확인`을 표시한다.

## 입력 모드

| 모드 | 구현 | 용도 | 제한 |
|---|---|---|---|
| 모드 1 | Windows SendInput | 일반 데스크톱과 대부분의 앱 | 잠금 화면, UAC 보안 데스크톱, 일부 보호 프로그램 |
| 모드 2 | 가상 키보드·마우스 HID | SendInput을 거부하는 앱 | WDK 드라이버, 코드 서명, 설치·재부팅 필요 |
| 모드 3 | 저수준 전용 HID/필터 | 호환성 최우선 환경 | 배포·보안·유지보수 비용이 가장 큼 |

모드 2와 3은 인터페이스만 준비되어 있고 이번 Preview에는 드라이버가 포함되지
않는다. 타사 드라이버 파일을 복사하지 않고 Comote 전용으로 개발·서명한다.

## 현재 보장 범위

- 물리 마우스와 키보드 연결은 필요하지 않다.
- 클라이언트는 관리자 권한 실행을 요구한다.
- 원격 Windows 사용자가 로그인된 대화형 세션이어야 한다.
- Windows 잠금 화면과 UAC 보안 데스크톱은 SendInput으로 제어할 수 없다.
- 연결 종료, 창 비활성화, PC 전환 시 눌린 키와 버튼을 모두 해제한다.
- 다중 모니터는 가상 데스크톱 좌표와 선택 모니터 원점을 함께 적용한다.

1. 테스트 서명 모드에서 가상 키보드·마우스 장치 열거
2. 일반 앱, 관리자 앱, 무입력장치 PC에서 입력 시험
3. 설치·삭제·업데이트·롤백 자동화
4. EV 코드 서명과 Microsoft 드라이버 서명 절차 완료
5. 모드 1 실패 시 모드 2로 전환하는 관리자 UI 제공
6. 입력 감사 로그에 전송, 클라이언트 수신, OS 주입 결과를 분리해 기록
