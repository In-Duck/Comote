# Comote 보안 화면 서비스 사용법

Preview 19부터 Comote Client는 Windows UAC와 관리자 프로그램 화면을 원격으로 표시하고 입력하기 위해 선택형 보안 화면 서비스를 제공합니다.

## 설치

1. 원격으로 사용할 PC에서 `ComoteClient.exe`를 실행하고 Comote 계정으로 로그인합니다.
2. 가상 HID를 사용할 경우 `고급 설정`에서 `가상 HID (FakerInput)`를 선택합니다.
3. 작업 표시줄의 Comote 아이콘을 우클릭하고 `보안 화면 서비스 설치/복구`를 누릅니다.
4. Windows 관리자 승인 창에서 `예`를 누릅니다. 이 승인은 최초 설치 또는 복구 때 한 번 필요합니다.
5. 설치가 끝나면 일반 Client 창은 종료되고 `Comote Secure Desktop Service`가 자동 시작됩니다.

PC 재부팅은 Comote 서비스 설치만으로는 필요하지 않습니다. FakerInput 설치 프로그램에서 재부팅을 요구하거나 설치 후 장치가 보이지 않을 때만 한 번 재부팅합니다.

## 사용

Manager에서 평소처럼 해당 PC를 더블클릭합니다. 원격 PC에서 관리자 권한 프로그램을 실행하면 UAC 보안 화면으로 자동 전환되며, 화면이 잠깐 검게 보인 뒤 승인 창이 나타납니다. 승인 또는 거절 후 일반 바탕화면으로 자동 복귀합니다.

- `가상 HID`: FakerInput 장치로 키보드와 마우스를 전송합니다.
- `SendInput`: Windows SYSTEM 세션의 전용 입력 스레드로 전송합니다.
- 화면이 전환될 때 눌린 키와 마우스 버튼은 먼저 해제하여 입력 고착을 방지합니다.
- 서비스가 중지되거나 사용자 세션이 바뀌면 기존 에이전트는 종료되고 새 활성 세션에서 다시 시작됩니다.

## 설정 변경

`ComoteClient.exe --setup`을 실행해 로그인한 뒤 PC 이름, 모니터, 입력 모드를 변경합니다. 저장하면 보안 화면 서비스가 새 설정으로 다시 시작됩니다.

## 제거

관리자 터미널에서 Client 폴더로 이동해 다음을 실행합니다.

```powershell
.\ComoteClient.exe --uninstall
```

서비스 제거 후 일반 실행 방식으로 돌아가려면 `ComoteClient.exe`를 다시 실행합니다.

## 보안 주의

이 서비스는 LocalSystem 권한으로 실행되므로 Comote 계정을 강한 비밀번호로 보호해야 합니다. 서비스용 로그인 토큰은 Windows DPAPI로 암호화되고 SYSTEM과 로컬 관리자만 접근할 수 있는 폴더에 저장됩니다. UAC 자체를 끄거나 승인을 자동으로 통과시키지는 않습니다. 원격 사용자가 화면에 표시된 UAC 창에서 직접 승인 또는 거절합니다.

게임과 안티치트의 정책은 제품마다 다릅니다. 가상 HID 사용이 모든 게임에서 허용되거나 제재되지 않는다고 Comote가 보장하지 않습니다.
