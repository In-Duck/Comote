# Comote 1.4 Demo 테스트 안내

## 구성

- `ComoteViewer.exe`: 서버 없이 실행되는 오프라인 다중 PC 관리 데모
- `ComoteHost.exe`: 실제 원격 연결용 Host 빌드
- `Comote Viewer Demo.cmd`: 데모 실행 바로가기

## 데모 실행

1. 압축을 풉니다.
2. `Comote Viewer Demo.cmd`를 실행합니다.
3. 목록 화면과 카드 화면을 전환해 봅니다.
4. `Ctrl`, `Shift`, `Ctrl+A`로 여러 컴퓨터를 선택합니다.
5. 선택한 컴퓨터나 카드에서 우클릭합니다.

## 데모에서 확인할 수 있는 기능

- 온라인/오프라인 상태, CPU, RAM, 디스크, 해상도 표시
- 목록/카드형 다중 PC 모니터링 화면
- 다중 선택과 최대 6개 제어창 동시 열기
- 새 그룹 생성, 기존 그룹 이동
- 이름/메모 변경
- 순서 앞으로/뒤로/원하는 위치로 이동
- 목록에서 삭제
- 입력 제어 모드 1/2/3 전환
- 드라이버 삭제: 구버전/모드2/모드3
- 드라이버 설치: 모드2/모드3
- Host 재실행/업데이트, Windows 재부팅/종료
- 외부 원격, 파일 전송, Wake-on-LAN 메뉴

## 안전한 데모 범위

오프라인 데모에서 드라이버 설치/삭제, 재부팅, 종료, 파일 전송 같은 시스템 명령은
화면과 작업 흐름만 확인하는 시뮬레이션입니다. 테스트 PC의 시스템을 실제로 변경하지
않습니다.

실제 원격 화면과 SendInput 키보드/마우스 제어는 Host와 Viewer가 새 Supabase/Pusher
서버에 연결된 뒤 두 대의 Windows PC에서 검증해야 합니다. 서버 재구축 순서는
`docs/BACKEND_REBUILD_GUIDE.md`를 참고하세요.

## 현재 입력 제어 구조

- 모드1: Windows `SendInput` 기반 구현
- 모드2/3: 자체 가상 HID 드라이버를 위한 확장 지점만 마련됨
- LinkIO 드라이버 파일은 라이선스와 서명 문제 때문에 포함하지 않음
