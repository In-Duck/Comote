# Comote 보안·출시 검토

검토 기준: 2026-07-21, Preview 16

## 이번 변경에서 보강한 항목

- Manager IP·VPN 주소·별도 접속 암호가 필요 없는 동일 계정 기본 연결
- ID와 실제 이메일 로그인 모두 지원하고 이중 도메인 변환 오류 제거
- Client 장치 등록을 Pusher 비공개 채널 인증보다 먼저 완료해 초기 연결 경쟁 조건 제거
- Manager의 빠른 초기 조회, 중복 폴링 차단, 정상 종료 시 저장소 정리
- 사설 TURN 환경 변수 지원과 공개 릴레이 사용 경고
- 공식 FakerInput v0.1.1 해시·서명 검증, 장애 시 SendInput 자동 전환
- 파일 크기 상한, 수신 크기·SHA-256 검증, 안전한 다운로드 경로
- 깨진 웹 대시보드와 로그인 UI를 UTF-8 기반의 단순한 화면으로 교체

## 상용 배포 전에 남은 필수 작업

1. 공개 TURN 릴레이를 팀 소유 coturn 또는 관리형 TURN으로 교체하고 단기 자격증명을 발급해야 합니다.
2. Supabase·Pusher 운영 키 교체, 서버 측 속도 제한, 감사 로그와 경보를 구성해야 합니다.
3. Windows 실행 파일과 설치 프로그램에 조직의 Authenticode 코드 서명을 적용해야 합니다.
4. 서로 다른 통신사·공유기·회사망에서 장시간 연결, 재접속, 다중 모니터, 파일 전송 부하 테스트가 필요합니다.
5. 외부 보안 검토와 개인정보 처리·보관 정책이 필요합니다.
6. FakerInput의 게임·안티치트 호환성과 계정 제재 없음은 보장할 수 없습니다.

따라서 현재 결과는 팀이 바로 설치해 시험할 수 있는 강화된 출시 후보 수준이며, 위 항목을 거치지 않은 상태를 완전한 상용 출시로 표현하면 안 됩니다.
