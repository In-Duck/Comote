# Comote 보안·안정성 검토

검토 기준: 2026-07-21, Preview 13 프로토타입

## 이번 변경에서 차단한 항목

- 자체 테스트 서명 Comote HID 드라이버와 배포 경로 제거
- 공식 FakerInput v0.1.1 MSI의 고정 SHA-256 및 Authenticode 검증
- FakerInput 장애 시 Client 중단 대신 SendInput 자동 폴백
- 연결·입력 채널 종료 시 입력 해제, 파일 채널 종료 시 수신 버퍼 폐기
- 입력 처리 예외가 WebRTC 콜백 전체를 중단하지 않도록 격리
- 파일 수신 256MB 상한, 선언 크기 검사, SHA-256 불일치 저장 차단
- 파일 이름 정리 및 전용 다운로드 폴더 저장
- 원격 실행 경로와 확장자 제한, UNC·스크립트 실행 차단
- 업데이트 패키지 HTTPS 및 SHA-256 검증
- 세션 토큰 원문 로그와 실제로 사용되지 않던 토큰 전달 제거
- 브랜치 push 시 GitHub Release를 자동 덮어쓰지 않도록 수동 게시로 변경

## 반드시 남아 있는 제약

1. Manager Hub TCP 45820 제어 채널은 TLS가 아닙니다. 등록 암호는 HMAC challenge로 원문 전송되지 않지만, 같은 네트워크의 능동 공격자에 대한 채널 기밀성·서버 인증은 제공하지 않습니다. LAN 또는 팀 VPN에서만 사용하세요.
2. 공개 STUN/TURN 서비스는 가용성·개인정보·운영 정책을 통제할 수 없습니다. 장기 사용 전 팀 소유 TURN 서버와 단기 자격증명으로 교체해야 합니다.
3. FakerInput은 제3자 MIT 오픈 소스 드라이버이며 무보증입니다. 게임·안티치트 호환성과 계정 제재 없음은 보장할 수 없습니다.
4. Windows UAC 보안 데스크톱, 잠금 화면, 다른 사용자 세션의 제어는 보장하지 않습니다.
5. 연결이 끊기는 바로 그 순간 드라이버 장치 자체가 응답하지 않으면 마지막 HID 해제 보고서를 전달할 수 없습니다. 이상 입력이 남으면 Client 종료 후 재부팅이 필요할 수 있습니다.
6. 현재 자동화 테스트는 빌드·패키징 중심입니다. 두 대의 실제 Windows PC, 다중 모니터, 절전/재접속, 각 대상 게임은 수동 검증이 필요합니다.

## 팀 배포 원칙

- 배포 ZIP의 `SHA256.json`을 보관하고 팀 내부 채널에 별도로 공유합니다.
- Manager 암호는 12자 이상 무작위 값으로 정하고 다른 서비스와 재사용하지 않습니다.
- Manager 방화벽은 사설/VPN 네트워크에만 허용합니다.
- 게임 테스트는 중요 계정이 아닌 허용된 테스트 환경에서 먼저 수행합니다.
- FakerInput 공식 버전을 바꿀 때 URL, 해시, 서명, 라이선스를 다시 검토합니다.
